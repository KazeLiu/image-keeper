# 图片指标测试工具设计

## 目标

在 ImageKeeper 首页增加一个独立的“图片指标测试”入口。用户可以临时导入多张图片、选择其中一张作为底图，并在图库卡片中查看其余图片相对底图的 pHash 汉明距离、主程序当前使用的低精度相似度，以及按需计算的标准 SSIM。

该工具只服务于算法观察和大图问题排查，不创建对比任务，不访问或写入业务数据库，不生成历史记录、报告或文件操作记录。关闭独立窗口后释放本次测试产生的前端状态、缩略图和计算结果。

## 范围

### 包含

- 首页两张主任务卡片下方的紧凑入口卡片“图片指标测试”。
- 独立 Tauri WebviewWindow 承载测试工具。
- 文件选择器批量导入和拖拽批量导入。
- 真实降采样缩略图、图片元数据和 `el-image` 原图预览。
- 单一底图选择，以及所有其他图片相对底图的 pHash 距离和低精度相似度自动计算。
- 单张卡片按需计算标准 SSIM。
- 计算进度、耗时、错误和重试状态。
- 本次独立窗口生命周期内的内存缓存。

### 不包含

- 创建、加载或修改正式对比任务。
- 写入 SQLite、历史任务或报告。
- 删除、移动、重命名或修改用户图片。
- 自动批量计算所有图片的标准 SSIM。
- 在本工具中提供正式工作流的“使用标准 SSIM”开关。
- 可编辑的算法阈值或用指标值直接给出删除建议。

## 入口与独立窗口

首页现有“选择新建任务”和“加载任务”继续并排显示。在它们下方新增一张明显更矮的紧凑入口卡片：

- 标题：`图片指标测试`
- 说明：`临时比较多张图片的 pHash、当前相似度与标准 SSIM，不保存记录`
- 点击后创建或聚焦标签固定为 `image-metrics-test` 的独立 Tauri WebviewWindow，不改变当前正式任务和首页状态。

入口卡片使用横向紧凑布局，建议高度约 `88–104px`，图标、标题和说明左对齐或顺序排列，不能与上方两张主任务卡片争夺同等视觉权重。

独立窗口建议初始尺寸 `1180×820`，最小尺寸 `840×600`，可调整大小，不允许重复创建。若窗口已存在，入口只将它显示、取消最小化并聚焦。测试界面使用专用路由 `/image-metrics-test`，主窗口仍保持 `/`。

独立窗口中的关闭按钮和操作系统标题栏关闭按钮遵循同一套关闭流程。当窗口已导入至少一张图片或存在计算状态时，关闭请求先被拦截并显示二次确认：`本次测试内容不会保存，关闭后将全部清空。确定关闭吗？`，操作为 `继续测试` 和 `确定关闭`。空窗口直接关闭，不显示无意义确认。高精度任务运行时仍允许用户确认关闭；确认后先使当前请求代次失效并清理内存，再真正关闭窗口。若用户选择继续测试，系统关闭请求被取消且全部状态保持不变。

## 顶部说明与操作区

独立窗口内容从上到下依次为算法说明、操作栏和图库。

算法说明使用紧凑的信息提示块，固定说明：

- `pHash 距离`：64 位感知哈希的汉明距离，范围为 `0–64`，越小表示视觉特征越接近；`0` 只代表 pHash 相同，不保证文件或像素完全一致。
- `低精度相似度`：主程序当前使用的灰度归一化像素差评分，显示范围为 `0–1`，越接近 `1` 越相似；它用于复现当前主程序表现，不是标准窗口式 SSIM。
- `标准 SSIM`：标准结构相似度，`1` 表示完全一致，越接近 `1` 通常越相似；标准公式可能产生负值，不把结果强制伪装成 `0–1`。
- 尺寸规则：两图尺寸不同时，将像素更多的一张缩小到像素更少的一张的宽高后比较。低精度相似度继续限制目标最长边为 `512px`；标准 SSIM 使用较小图片的完整分辨率，不应用 `512px` 限制，也不主动放大较小图片。

操作栏包含：

- `选择图片`：打开支持多选的系统文件选择器。
- `清空全部`：清空当前测试数据；有图片时才可用。
- 图片计数，例如 `已加载 12 张`。
- 辅助文字：`支持多选，也可以将图片拖入窗口`。

不再增加“开始全部计算”按钮。选择底图后，pHash 距离和低精度相似度自动进入队列；标准 SSIM 始终由单张卡片触发。

## 导入与缩略图

### 导入行为

- 文件选择和拖拽使用同一套校验、去重和加载流程。
- 按规范化后的绝对路径去重；重复导入同一文件时跳过并给出简短提示。
- 保持用户首次导入顺序；后续追加的图片排在末尾。
- 不支持或无法解码的文件不创建正常卡片，并在独立窗口内给出包含恢复建议的错误提示。
- 单个文件加载失败不影响其他文件。

### 性能约束

卡片不能把原图交给 WebView 后只靠 CSS 缩小。后端解码图片后，生成最长边不超过 `200px` 的真实缩略图；前端以 Blob URL 或等价的短生命周期资源显示，并在图片移除或独立窗口关闭时释放。

批量导入使用最多 `3` 个并发解码任务，避免串行导入造成“卡死”错觉，也避免无限并发解码超大图片造成内存峰值。用户完成文件选择或拖入后，界面立即为全部待处理图片预留骨架卡片；单张图片完成后即替换对应占位。

原图路径只提供给 `el-image` 的预览列表。用户点击缩略图时才打开原图预览；卡片展示阶段不得预解码全部原图。预览支持同一批图片的前后切换。

## 图库与卡片

图库采用响应式 CSS Grid，图片按从左到右、从上到下排列。默认窗口使用两列紧凑卡片，缩略图显示区域最高 `200px`，保持原始宽高比，不裁切主体，也不让大图撑开布局。

每张卡片包含：

1. 缩略图预览区。
2. 文件名，过长时省略并通过 tooltip 查看完整名称。
3. 文件大小；卡片不显示原始分辨率。
4. 相对底图的指标区。
5. 移除当前图片的操作。

点击卡片中除图片、移除按钮和指标按钮之外的区域，将该图片设为唯一底图。点击图片只打开 `el-image` 原图预览，不改变底图。底图通过高对比度边框、浅色背景和可读的“底图”标签共同表达，不能只依赖颜色。

底图的指标区仅显示 `底图`。其他卡片使用单行紧凑指标：`pHash 距离：6 · 低精度 SSIM：0.982314 · 标准 SSIM：点击计算`。默认两列宽度下保持一行；窗口过窄时允许自然换行，不能产生横向滚动。

pHash 距离只显示 `0–64` 的距离整数，不显示容易被误认为进度的 `0 / 64`。距离 `0` 表示两张图的 64 位感知哈希相同，不保证原始文件或像素完全一致；完整哈希继续通过 tooltip 提供。

数据值使用等宽或 tabular 数字，默认显示 6 位小数；完整精度可通过 tooltip 或复制操作读取。加载和计算中使用骨架、旋转图标或明确文字，不用布局跳动表达状态。

未选择底图时，图库上方提示 `点击一张图片，将它设为底图`，其他卡片指标区显示等待状态。移除底图后清空当前底图选择并回到该状态，不自动指定另一张图片。

## 计算模型

### 图片级计算

每张图片导入后独立计算并在当前独立窗口内缓存：

- 规范化文件标识。
- 文件名、文件大小、宽高和可预览地址。
- 64 位 pHash 原始值。
- 最长边不超过 `200px` 的缩略图。

pHash 原始值保留在内存模型中，卡片默认突出显示相对底图的汉明距离，避免长哈希值挤压指标区。需要核对时可在 pHash 距离的 tooltip 或复制详情中同时看到底图和当前图片的完整 pHash。

### 低精度批量计算

选择或更换底图后：

1. pHash 汉明距离通过已缓存的两个哈希立即计算。
2. 其他图片与底图的低精度相似度自动排入有界队列。
3. 卡片分别展示等待、计算中、成功或失败状态。
4. 更换底图时，旧请求的返回值不得写入新底图对应的卡片状态。

低精度计算必须复用主程序当前算法实现和相同的 `512px` 归一化规则，不能在测试工具里复制一份行为不同的公式。

### 标准 SSIM 按需计算

标准 SSIM 默认不计算。用户点击某张非底图卡片的 `点击计算` 后，只计算该图片与当前底图这一对：

- 点击后显示 `计算中…` 和耗时状态，避免重复提交。
- 同时只执行一个标准 SSIM 任务；后续点击进入队列或给出忙碌反馈，避免多张大图并发造成内存峰值。
- 结果显示 6 位小数和计算耗时，例如 `0.991284 · 2.43 s`。
- 失败时显示简短原因和 `重试` 操作。
- 结果以无序文件对和文件指纹作为本次会话缓存键；在独立窗口未关闭且文件未变化时，切换底图后再次比较同一对可复用结果。
- 文件在导入后发生大小或修改时间变化时，不复用旧缓存，并提示重新载入。

标准 SSIM 核心实现应放在可复用的 Rust 算法模块中，测试命令只负责读取文件、归一化、调度和返回结果。后续正式工作流增加标准 SSIM 开关时复用同一实现；若另一项并行需求已经引入该核心，则本功能直接复用，不能再创建第二套标准 SSIM。

## 前后端边界

### 前端

前端新增独立路由视图和聚焦于窗口状态的图库组件，负责：

- 在主窗口创建或聚焦测试 WebviewWindow。
- 在测试窗口拦截系统关闭请求并执行确认与清理。
- 文件选择与拖拽事件。
- 图库卡片、底图选择和 `el-image` 预览。
- 任务状态、内存缓存索引和过期结果防护。
- Blob URL 等短生命周期资源的释放。

正式对比 Pinia store 不承载该状态，防止临时测试污染任务状态。若组件体积增长，应把 API 类型和纯状态逻辑拆到独立模块，不把算法计算放在 Vue 组件中。

### Tauri / Rust

新增无数据库依赖的命令边界，职责建议拆为：

- 加载单张图片的元数据、pHash 和 `200px` 缩略图。
- 计算指定图片对的主程序低精度相似度。
- 计算指定图片对的标准 SSIM。

命令只接收明确的图片路径和必要参数，不创建扫描记录或对比运行。CPU 密集型解码和指标计算不得阻塞 Tauri 异步运行时或前端主线程，应在阻塞任务池中执行并限制并发。

## 状态、错误与清理

- 空状态：显示拖拽区域和“选择图片”主操作。
- 图片加载中：文件选择完成后立即显示全部稳定卡片占位，最多并行加载三张，避免串行无反馈和无限并发内存峰值。
- 未选底图：提示选择底图，不启动配对计算。
- 低精度失败：只标记对应卡片并提供重试，不影响其他图片。
- 高精度失败：保留低精度结果，显示原因和重试按钮。
- 原图预览失败：卡片仍保留元数据和指标，提示文件可能被移动或修改。
- 清空：使当前请求代次失效，释放缩略图 URL、预览列表、内存缓存和组件状态。
- 关闭：空窗口直接关闭；已有图片或计算状态时先确认“不保存并清空”，用户选择“继续测试”则保持全部状态，选择“确定关闭”才执行清理并关闭 WebviewWindow。
- 异步任务无法物理取消时，其完成结果必须被代次标识丢弃，不能写回已移除图片、已切换底图或已关闭窗口。

错误信息不输出完整内部堆栈；用户可见文案包含失败对象、原因和下一步操作。绝对路径只在用户主动查看文件详情时展示。

## 可访问性与交互细节

- 卡片支持键盘聚焦，`Enter` 或空格可设为底图。
- 图片预览、移除、计算高精度和关闭按钮都有可读标签。
- 底图状态使用边框、背景和文字三种信号，屏幕阅读器声明 `selected`。
- 所有按钮有明确 hover、pressed、disabled 和 focus-visible 状态。
- 拖拽不是唯一导入方式，始终保留系统文件选择器。
- 动画限制在 `150–300ms` 的颜色、阴影或透明度变化，并尊重 reduced-motion。
- 顶部说明文字和指标文本满足正常文本 `4.5:1` 对比度。

## 验证策略

### Rust 单元测试

- pHash 结果为稳定的 64 位表示，汉明距离边界为 `0–64`。
- 相同图片的 pHash 距离为 `0`，标准 SSIM 接近 `1`。
- 低精度命令与主程序现有算法对同一图片对返回一致结果。
- 不同分辨率时，大图按约定缩小到小图尺寸；低精度最长边限制为 `512px`，标准 SSIM 不使用该限制。
- 标准 SSIM 使用固定参考图或公开参考向量验证，不能只用“相同图片等于 1”证明实现正确。
- 真实缩略图最长边不超过 `200px`，宽高比保持一致。
- 无效路径、不支持格式、解码失败和文件变化返回可区分错误。
- 测试命令不需要 Repository 或数据库连接。

### 前端测试

- 首页下方紧凑卡片创建测试窗口；重复点击只聚焦已有窗口，不改变正式任务状态。
- 文件选择与拖拽共用导入逻辑，并正确去重。
- 点击卡片设为底图；点击图片只打开预览，不切换底图。
- 更换底图触发新的低精度队列，旧结果不能覆盖新状态。
- 标准 SSIM 只有点击单张卡片后才触发，且不会自动全量运行。
- 移除底图、清空和关闭窗口正确释放状态与 Blob URL。
- 空窗口直接关闭；非空窗口通过界面关闭按钮或系统标题栏关闭时均出现不保存确认，系统关闭回调不得等待由自身触发的第二次关闭事件，取消关闭后状态不变。
- 成功、等待、计算中、失败和重试状态均可见且可键盘操作。

### 手工验收

- 导入多张普通图片和多张超大图片，选择完成后立即出现全部占位，最多三张并行加载，图库滚动保持可操作。
- 图片按导入顺序从左到右、从上到下排列，缩略图最高 `200px`。
- 卡片不显示原始分辨率；点击缩略图可用 `el-image` 查看原图。
- 选择底图后，其他卡片陆续出现 pHash 距离和低精度结果，底图卡片只显示“底图”。
- 点击一张卡片的高精度操作只计算该图片对，其他卡片仍保持未计算。
- 用相同图、重编码图、不同分辨率图、明显不同图检查三个指标的方向和说明一致。
- 非空窗口关闭时明确提示测试内容不会保存；选择“继续测试”保留当前图库，选择“确定关闭”后清空并退出。
- 关闭窗口并重新打开后为空状态，没有上次测试记录。

## 完成标准

功能完成需要同时满足：首页下方紧凑入口和独立 Tauri 窗口符合现有 Element Plus 风格；重复点击入口只聚焦同一窗口；多图导入立即给出完整占位反馈并有界并发；拖拽、底图选择、200px 真实缩略图和原图预览可用；pHash 距离与低精度结果自动计算；标准 SSIM 仅按单卡片请求并使用较小原图完整分辨率计算；系统标题栏关闭可用且联动确认；全过程不写业务数据库或历史记录；自动化测试和手工验收通过。
